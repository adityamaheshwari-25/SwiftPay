# IaaS vs. Recommended PaaS Approach

| IaaS approach                | Recommended PaaS approach       |
| ---------------------------- | ------------------------------- |
| Linux virtual machine        | Azure App Service               |
| Install Java manually        | Managed Java runtime            |
| Configure Nginx manually     | Managed application ingress     |
| Install PostgreSQL manually  | Azure Database for PostgreSQL   |
| Patch operating system       | Azure manages platform patching |
| Manually manage certificates | Managed HTTPS capabilities      |
